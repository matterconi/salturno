# SalTurno

A simple staff scheduling application built to streamline weekly shift planning for restaurants and small businesses.

## Overview

SalTurno was one of my early React projects, created to simplify employee scheduling and weekly shift allocation.

The application allows managers to assign staff members to opening, service, and closing shifts across an entire week through a straightforward dashboard interface.

While the functionality may seem simple today, building a complete business-oriented web application from scratch provided valuable experience in UI design, state management, and workflow modelling.

## Tech Stack

* React
* JavaScript
* CSS
* Local State Management

## Features

* Weekly scheduling dashboard
* Employee assignment per shift
* Opening, service, and closing shift management
* Simple and intuitive interface
* Fast schedule updates without page reloads

## Why I Built It

The goal was to explore how software can simplify operational tasks that are traditionally handled with spreadsheets, paper schedules, or messaging apps.

Rather than focusing on visual effects or advanced engineering challenges, this project was primarily about understanding business workflows and translating them into a usable interface.

## Key Learnings

* Building interfaces around real operational needs
* Structuring application state for multi-day schedules
* Designing simple user experiences for non-technical users
* Managing repeated UI patterns efficiently
* Thinking in terms of business processes rather than individual screens

## Historical Context

This project was built approximately two years ago as part of my early journey into web development.

Compared to modern AI-assisted development workflows, the implementation itself is relatively straightforward. However, the project remains a useful milestone because it reflects an early focus on solving practical business problems through software.
